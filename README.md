# Retail Sales Analytics Dashboard

## Project Overview

A Flask-based data analytics dashboard that analyzes retail sales data and provides business insights through interactive visualizations and machine learning predictions.

## Features

* Sales Performance Dashboard
* Region-wise Sales Analysis
* Category-wise Sales Distribution
* Monthly Sales Trend Analysis
* Sales Forecasting using Machine Learning
* Interactive Plotly Visualizations

## Technologies Used

* Python
* Flask
* Pandas
* Plotly
* Scikit-learn
* HTML/CSS

## Dataset

Retail sales dataset containing:

* Sales
* Profit
* Quantity
* Discount
* Category
* Region
